# Жёсткий аудит Shopify Lab v0.2

## Что уже сильно
- Ядро цикла покрыто доменными сущностями и сервисами.
- Есть rule-based scoring, unit economics, final decision, postmortem.
- Есть reproducible demo-cycle и тесты для критичных правил.

## Главный практический разрыв до этого шага
- Не было единого экспортируемого результата цикла.
- Нельзя было получить единый пакет для чтения человеком и для последующей автоматизации.
- Данные были распределены по сущностям, но не собирались в единый отчёт-артефакт.

## Риски без экспорта
1. Потеря контекста при передаче между ролями.
2. Сложность аудита решений и сравнения циклов.
3. Повышенная стоимость интеграции в agent-пайплайн в будущем.

## Принятое минимальное улучшение v0.3-step
Реализован **cycle report export** как единый пакет в двух форматах:
- JSON (machine-readable)
- Markdown (human-readable)

С принципами:
- единый источник данных (service-layer сборка)
- явная маркировка пропусков (`status: missing`)
- понятная ошибка на несуществующий `hypothesis_id`
