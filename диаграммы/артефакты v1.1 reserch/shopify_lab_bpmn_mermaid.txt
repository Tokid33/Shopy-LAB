DIAGRAM 1 — MAIN DEMAND EVALUATION PROCESS
```mermaid
flowchart TB
    subgraph L1["Лейн 1 · Product Owner / Аналитик"]
        S((Старт))
        H["Создать Product Hypothesis"]
        P["Задать входные параметры<br/>категория, price range, angle,<br/>ограничения и hypothesis source"]
    end

    subgraph L2["Лейн 2 · Shopify Lab Core / API / Orchestrator"]
        R["Создать Agent Run<br/>и research tasks"]
        F{"Параллельный запуск<br/>исследовательских задач"}
        J{"Все обязательные агенты<br/>завершены или истёк SLA?"}
        W["Ждать / retry / timer SLA"]
        N["Нормализация evidence<br/>в normalized signals"]
        C{"Хватает обязательных<br/>сигналов для скоринга?"}
        V["Верификация<br/>повторный сбор / manual review / source check"]
        SC["Скоринг товара"]
        RF{"Есть critical red flags?"}
        CF{"Есть конфликт сигналов<br/>или low confidence?"}
        DC["Сформировать Decision Card<br/>+ rationale + next step"]
        VD{"Итоговый verdict"}
        M["Снимать метрики этапов<br/>coverage, confidence, lead time,<br/>retry count, verification rate"]
    end

    subgraph L3["Лейн 3 · Агентная система"]
        A1["Scout Agent<br/>рынок / ads / trends"]
        A2["VoC Agent<br/>reviews / pains / objections"]
        A3["Supplier Agent<br/>cost / shipping / risk"]
    end

    subgraph L4["Лейн 4 · Выход процесса"]
        PASS["PASS<br/>передать в Offer / Page Stage"]
        HOLD["HOLD<br/>дособрать данные / ручная проверка"]
        REJECT["REJECT<br/>закрыть гипотезу"]
        E((Конец))
    end

    S --> H --> P --> R --> F
    F --> A1 --> J
    F --> A2 --> J
    F --> A3 --> J
    J -- "нет" --> W --> J
    J -- "да" --> N --> C
    C -- "нет" --> V --> N
    C -- "да" --> SC --> RF
    RF -- "да" --> REJECT --> E
    RF -- "нет" --> CF
    CF -- "да" --> V
    CF -- "нет" --> DC --> VD
    VD -- "PASS" --> PASS --> E
    VD -- "HOLD" --> HOLD --> E
    VD -- "REJECT" --> REJECT

    N -.-> M
    SC -.-> M
    DC -.-> M
```

DIAGRAM 4 — DECISION LOGIC / SCORING
```mermaid
flowchart TB
    S(("Start decision logic"))
    I["Загрузить normalized signals"]
    M{"Есть mandatory data?"}
    H1["HOLD<br/>недостаточно данных"]
    RF{"Есть hard red flags?"}
    RFN["Hard red flags:<br/>margin below floor<br/>compliance risk<br/>shipping too slow<br/>fragility / return risk high<br/>supplier unverifiable<br/>3-second clarity = fail"]
    R1["REJECT<br/>critical risk"]
    C1["Вычислить sub-scores:<br/>clarity 15<br/>wow/demo 15<br/>demand 20<br/>creative 10<br/>supplier 15<br/>economics 15<br/>logistics 10"]
    T1["total_score = сумма sub-scores"]
    C2["Рассчитать confidence:<br/>source_count, agreement,<br/>freshness, completeness"]
    G{"Есть signal conflict<br/>или high variance?"}
    H2["HOLD<br/>secondary verification"]
    TH{"Пороговый verdict"}
    P1["PASS<br/>score >= 75 и confidence >= 0.70"]
    H3["HOLD<br/>60-74 или confidence 0.50-0.69"]
    R2["REJECT<br/>score < 60"]
    OUT["Сформировать decision_card<br/>verdict + rationale + next_step"]

    S --> I --> M
    M -- "нет" --> H1 --> OUT
    M -- "да" --> RF
    RFN -.-> RF
    RF -- "да" --> R1 --> OUT
    RF -- "нет" --> C1 --> T1 --> C2 --> G
    G -- "да" --> H2 --> OUT
    G -- "нет" --> TH
    TH -- "PASS" --> P1 --> OUT
    TH -- "HOLD" --> H3 --> OUT
    TH -- "REJECT" --> R2 --> OUT
```

DIAGRAM 5 — EXCEPTION HANDLING PROCESS
```mermaid
flowchart TB
    E(("Boundary Error / Timeout Event"))
    C{"Класс исключения"}

    M1["Missing data<br/>по обязательному блоку"]
    M2["Targeted retry<br/>по missing agent / source"]
    M3{"Данные получены<br/>до SLA?"}
    M4["Вернуть в normalization / scoring"]
    M5["HOLD + manual enrichment task"]

    X1["Conflict signals<br/>между источниками"]
    X2["Secondary source collection<br/>+ cross-check"]
    X3{"Конфликт снят?"}
    X4["Вернуть в decision logic"]
    X5["HOLD / analyst review"]

    R1["Critical risk"]
    R2["Лог risk evidence"]
    R3["REJECT"]

    T1["System / parser / storage / API failure"]
    T2["Retry with backoff<br/>1..N attempts"]
    T3{"Восстановлено?"}
    T4["Продолжить stage"]
    T5["Create incident / alert<br/>Pause run"]
    T6["HOLD technical"]

    E --> C
    C -- "Нет данных" --> M1 --> M2 --> M3
    M3 -- "да" --> M4
    M3 -- "нет" --> M5

    C -- "Конфликт сигналов" --> X1 --> X2 --> X3
    X3 -- "да" --> X4
    X3 -- "нет" --> X5

    C -- "Критический риск" --> R1 --> R2 --> R3

    C -- "Техническая ошибка" --> T1 --> T2 --> T3
    T3 -- "да" --> T4
    T3 -- "нет" --> T5 --> T6
```
